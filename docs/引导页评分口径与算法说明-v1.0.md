# 引导页报告评分口径与算法说明 v1.0

## 1. 目的

- 让“评分文案”和“代码实现”口径一致，可追溯、可复核。
- 降低用户对“分数如何得出”的理解偏差。

## 2. 评分维度与总分

- 维度：`饮食`、`体质`、`作息`、`心理`、`运动`
- 总分：5 个维度分数的算术平均（四舍五入）
- 主要改善方向：5 维中最低分对应维度

实现文件：`src/utils/healthAssessmentScoring.ts`

## 3. 各维度规则（与实现一一对应）

### 饮食（diet）

- 基准分：50
- 填写饮食偏好：+15
- 含健康偏好（balanced/high_protein/mediterranean/vegetarian）：+15
- 饮水：
  - >=8 杯：+20
  - 6-7 杯：+10
  - 4-5 杯：+5

### 体质（fitness）

- 基准分：50
- BMI：
  - 18.5-24.9：+30
  - 17-18.5 或 25-27：+15
  - 其他：+5
- 健康关注项：
  - 含 diabetes/heart_disease/high_blood_pressure：-20
  - 其他非空：-10
  - 为空：+20

### 作息（rest）

- 基准分：50
- 睡眠：
  - 7-9 小时：+40
  - 6-7 小时：+25
  - 5-6 小时：+10
- 活动水平：
  - sedentary：+10
  - light/moderate：+5

### 心理（psychology）

- 基准分：60
- 设置了 fitnessGoal：+20
- 健康关注项：
  - 含 stress/anxiety/depression/insomnia：-20
  - 否则：+20

### 运动（exercise）

- 基准分：40
- exerciseHabits 每项：+8
- activityLevel：
  - sedentary: +0
  - light: +10
  - moderate: +20
  - active: +30
  - very_active: +40

## 4. 边界与约束

- 单维分数范围：0-100（超界后夹紧）
- 总分范围：0-100
- 未填写字段不触发对应加减分

## 5. 可解释性接口

已提供规则级明细函数：

- `calculateHealthScoreBreakdown(data)`

返回每个维度的规则命中明细（rule + delta），用于：

- 报告页“为什么是这个分数”的展示
- 线下抽样复核
- 回归测试

## 6. 回归建议（上线前）

- 抽样 3 份报告，逐项核对“输入 -> 规则命中 -> 维度分 -> 总分”
- 对照本说明与 `src/utils/healthAssessmentScoring.ts`，确保无口径偏差
